### 🧠 SiliconMind — AI-Driven FPGA Design Optimization

> **Problem:** Manual FPGA optimization is slow, error-prone, and cycles through long re-synthesis loops.
> **Solution:** An end-to-end ML platform that ingests Vivado synthesis reports and auto-generates optimization recommendations.

- Trained **XGBoost/MLP ensemble** on synthesis report features — achieved **92% prediction accuracy**
- Integrated tabular **Q-Learning RL agent** for iterative design-space exploration
- Built **FastAPI** backend handling ML inference, synthesis log parsing, and structured REST delivery
- Designed **interactive Recharts dashboards** (168 LUTs · 0.085W power · 6.23ns critical path)
- Implemented **multi-turn AI chat** with Context API state management and streaming response rendering
- Deployed on Vercel with **GitHub Actions CI/CD pipeline**

### ⚡ Shortify — Scalable URL Shortener SaaS

> High-performance URL management platform built for scale, analytics, and reliability.

- **Base62 encoding** for collision-free short URL generation at scale
- **Redis caching** layer reducing redirect response time from **200ms → 50ms (75% improvement)**
- **MongoDB schema** with compound indexing for high-read throughput
- **Recharts analytics dashboard** tracking click-through rates and traffic metrics
- Containerized with **Docker**, deployed via **GitHub Actions CI pipeline**
- Comprehensive **Jest integration tests** covering redirect, auth, and analytics flows
